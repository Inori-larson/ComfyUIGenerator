# 分镜生成最高设计规则

本文件是 ComfyUIGenerator 分镜批量生成、复盘与修 bug 的**最高规则**。
当本文与任何标签、阶段、rank、相似度等启发式规则冲突时，以本文为准。

配套 opencode skill：`generation-postmortem`（复盘/修复流程、Story Contract、Finding 与归档 schema）。

## 1. 一个好剧本的唯一标准

```text
符合剧情设计
+ 剧情流畅连贯
+ 人物服装、动作流畅连贯
= 好的剧本提示词
```

判断任何镜头/标签是否有问题，先问：**它是否违背了当前剧本大纲的设计？**
不违背，就不是问题。

## 2. 质量重心在大纲，下游只兜底

- 最该把控的是“分镜 / 剧本大纲”。大纲不出问题，后续就不会出问题。
- 大纲阶段先产出**镜头蓝图（shot blueprint）**：
  - 用户里程碑保持原顺序，不调换、不遗漏；
  - 最后一个剧本 beat（终局）锁定到最后一镜；
  - 镜数多于里程碑时，多余镜头在终局之前细分微节拍，不放到终局之后。
- 下游 script / tag / 校验的目标是**尽量不出错、不触发兜底**，而不是靠兜底层层补救。
- 复盘与修 bug 时，根因若在大纲，必须回到大纲修；禁止在下游打标签补丁掩盖。

## 3. 标签事实永远不等于剧情结论

任何标签都不能仅凭自身触发强制拦截（包括但不限于）：

- **射精不等于终章**：可以口交内射、颜射、射在身上，故事仍可继续。
- 阶段“回退”不一定是回退：可能是剧本的体位 / 场景设计。
- phase 长期不变、非相邻镜头标签高重合，可能是合理的连续表达。
- “终局 / 重启 / 回退”只能由**剧本大纲设计**判定，不能由关键词、rank、相似度判定。

## 4. 下游校验的兜底定位（默认从宽）

1. **确认项（advisory，不阻断、不重写）**
   射精、阶段回落、phase 停滞、非相邻高相似等。
   文案必须写明“若剧本就是这样设计则完全允许、无需修改”；只有确认违背大纲时才调整。

2. **硬阻断（仅客观破坏连贯）**
   - 连续镜头逐字复制、剧情不推进；
   - 服装状态自相矛盾或违背**初始服装设计**
     （初始服装设计视为剧情设计的一部分）。

兜底只能拦截“画面与大纲 / 初始设计不一致或客观断裂”，
不得因为标签本身限制剧情。规则越写越死本身就是缺陷。

## 5. 语义只能由 AI 生成

- 剧情、顺序、动作、姿势、表情、构图、服装状态、positive/negative 的语义，
  只能由 AI 依据 premise、Story Contract 与结构化 finding 生成。
- 应用侧只做：解析、持久化、监督审查、拒绝、请求重写、无语义副作用的格式规范化、证据归档。
- AI 漏拍 / 错拍 / 语义模糊时，应用侧不得代笔，只能拒绝并要求 AI 重新生成。
- 禁止：角色名/服装/动作/镜号的专属条件分支、“关键词 → 剧情标签”注入、
  用历史 golden 批次补全新故事。

## 6. 复盘 / 修 bug 强制自问

- 这个拦截/修复依据的是剧本大纲设计，还是某个标签/关键词？若是后者，撤销。
- 能否在大纲阶段就避免？能就上移到大纲，而不是加重下游。
- 去掉这条规则后，符合剧情的合理表达是否反而被拦？是则规则过死。
- 修后是否检查了最终 PNG node6/node7、做了幂等、跨故事反例与全量测试？
